# E-Commerce Database Management System

## Project Overview
This project is a simple E-Commerce Database Management System created using MySQL.

The database is designed for an online shopping company called **ShopEasy**. It manages customer details, products, categories, shopping carts, orders, payments, addresses and product reviews.

## Technology Used
- MySQL
- SQL
- MySQL Workbench

## Database Tables
The project contains 10 tables:

1. customers
2. categories
3. products
4. cart
5. cart_items
6. addresses
7. orders
8. order_items
9. payments
10. reviews

## SQL Concepts Used
- CREATE DATABASE and CREATE TABLE
- INSERT, UPDATE and DELETE
- SELECT, WHERE and ORDER BY
- INNER JOIN, LEFT JOIN and RIGHT JOIN
- GROUP BY and HAVING
- COUNT, SUM, AVG, MIN and MAX
- Subqueries
- Views
- Window Functions
- RANK() and ROW_NUMBER()
- LAG() and LEAD()
- Stored Procedures

## Project Analysis
The project contains **30 scenario-based SQL questions** divided into:

- Basic — Questions 1 to 10
- Intermediate — Questions 11 to 25
- Advanced — Questions 26 to 30

These queries are used to analyze products, customers, orders, payments and sales.
